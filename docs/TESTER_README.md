# Backline — Tester Install Guide

Thanks for trying **Backline**, a music‑to‑picture editor: drop in a locked video, fit
and cut library music to it, mix, and export the mix back against picture.

## Install (macOS)

1. Open **Backline.dmg**.
2. Drag **Backline** onto the **Applications** folder.
3. **First launch:** right‑click (or Control‑click) the Backline app → **Open** → **Open**.
   - You only do this the first time. macOS shows a warning because this build isn't
     Apple‑notarized yet (that's a paid Apple step we add before public release). It's safe.
   - If you don't see an "Open" button: System Settings → Privacy & Security → scroll down →
     **Open Anyway**.

## Good to know

- **Apple Silicon Macs (M1/M2/M3):** this is an Intel build, so macOS may ask to install
  **Rosetta** the first time. Click **Install** and it runs fine. (A native build comes later.)
- **Microphone prompt:** Backline asks for mic access only so you can record takes. Allow it
  if you want to record; otherwise it's not needed.
- **Stem splitter (optional):** the first time you use *Split Stems*, it downloads an AI model
  (needs internet, one‑time, a couple minutes). Everything else works fully offline.

## A 5‑minute test run

1. New project → **import a video** (any .mov/.mp4).
2. Drag in **a song or two** (or a few cues).
3. **Play** — the video follows the audio. Try **cut / trim / fade** a clip.
4. Open the **mixer**: try a **Submix** bus, watch the **LUFS** readout on the Master strip.
5. Click the big **counter** (top) to switch readout (Timecode / Feet+Frames / etc.).
6. **Export** the mix (or export to video). Try **Export → loudness‑normalized**.
